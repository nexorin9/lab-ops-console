## 1. 三个状态

### 起始态 —— 信息科面板首屏

打开浏览器访问 `http://<host>:3000/`：

- 顶部一条状态条：服务状态（运行中）、已连接通道数、当前时间
- 主体区上半部分：**设备列表**，每行一台仪器 —— 仪器名、通道类型（HL7 / ASTM / 串口 / 私有）、状态圆点（绿=有心跳 / 红=断开）、最近心跳时间（`YYYY-MM-DD HH:mm`）、最近一条样本标识、解析成功或失败标记
- 主体区下半部分：**最近样本区**，滚动显示最近推送的若干条结果摘要
- 右侧：**调试区**，可按患者或日期检索已写入的检验结果

画面上应该同时能回答两个问题：**这台仪器还活着吗？**（心跳与状态点）、**它最近推的东西进来了吗？**（最近样本标识与解析标记）。

### 首个可用瞬间 —— 仪器推来一段结果后 1 秒内

同一页面，对应通道那一行发生变化：

- 心跳时间更新为刚刚
- 「最近一条样本」从空变为本次报文标识
- 解析标记从空变为成功（若失败则为失败 + 错误码）
- 最近样本区顶部插入一条新记录

院内端点侧：收到该标本的全部检验结果（每项一条）与一份关联全部结果的报告。

这一瞬间是「通道接对了没有」的判据 —— 如果这一秒什么都没发生，多半是协议类型或字段偏移配错了。

### 成形态 —— 危急值闭环

切到护士站大屏 `http://<host>:3000/critical`：

- 未处置的危急值以**红色边框卡片**呈现，卡内是：患者标识（哈希占位）、检验项名称、结果数值 + 单位、检出时间、危急级别标识、候选接收人（标注来源与置信度）
- 卡片下方两个操作按钮：「已接收」「已处置」
- 已接收的卡片边框转为橙色并展开处置备注输入框
- 已处置的卡片移入右侧「已办」列表，显示处置人与处置时间
- 大屏顶部横幅显示当前未处置危急值数量

信息科面板同一时刻显示该危急值在处置单列表中的当前状态与最近留痕。

## 2. 画面类型

| 画面 | 类型 | 说明 |
|------|------|------|
| 信息科面板 `/` | 浏览器界面 | 设备列表 + 最近样本 + 危急值列表 + 调试区 |
| 护士站大屏 `/critical` | 浏览器界面 | 危急值卡片流 + 已办列表 |
| 命令行 `status` | 终端会话 | 通道状态、心跳、最近样本、最近错误码 |
| 命令行 `export` | 导出的报告页 | 月度闭环台账 CSV / PDF |

与本轮交付形态一致：常驻 Node 进程 + Express 与 WebSocket 同端口，浏览器页面与命令行两条入口，不另起独立前端工程。

## 3. 视觉语言

### 配色（design token 统一管理，落地在 `src/gateway/static/tokens.css`）

| 语义 | 变量 | 色值 | 用处 |
|------|------|------|------|
| 危急 | `--color-critical` | `#d92d20` | 危急值卡片边框、危急级别标识 |
| 高危 | `--color-high` | `#f79009` | 高危级别标识 |
| 正常 | `--color-ok` | `#12b76a` | 心跳状态点、解析成功 |
| 警告 | `--color-warn` | `#fdb022` | 通道降级、待补推队列 |
| 信息 | `--color-info` | `#2e90fa` | 已接收状态、主操作按钮 |
| 中性文本 | `--color-text` | `#101828` | 正文 |
| 弱文本 | `--color-text-muted` | `#667085` | 辅助说明、时间戳 |
| 分隔线 | `--color-border` | `#eaecf0` | 表格行分隔、卡片边框（中性态） |
| 页面底色 | `--color-bg` | `#f9fafb` | 面板背景 |
| 卡片底色 | `--color-surface` | `#ffffff` | 卡片 / 表格 |

**危急态不只靠颜色区分**：同时带边框加粗 + 「危急」文字标签 + 卡片左侧色条，色觉障碍下仍可辨。

### 字体族

```
--font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
               "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
--font-family-mono: ui-monospace, SFMono-Regular, Menlo, Consolas, "Courier New", monospace;
```

只用系统字体栈，不下载字体文件。层级四级：页面标题 20px / 区块标题 16px / 正文 14px / 辅助文字 12px。数值、时间戳、状态码用等宽字体并 `font-variant-numeric: tabular-nums` 对齐。

### 信息层级

1. **最显眼**：危急值卡片（红框、放大数值、白色大字）
2. **次显眼**：设备心跳状态点与通道状态
3. **再次**：最近样本列表、处置单列表
4. **最弱**：时间戳、样本标识、辅助说明

### 留白密度

- 8px 栅格：间距取 8 / 12 / 16 / 24 / 32
- 卡片内边距 16px，卡片间距 16px；大屏卡片内边距 24px
- 表格行高 40px（面板）/ 48px（大屏）；大屏首屏目标可见 6–8 张危急值卡片
- 圆角：卡片 8px，按钮 6px，徽标 4px；阴影仅卡片一级

### 图标

用内联 SVG（图标集随静态页提供），不使用 emoji。

## 4. 必须可达的约束

本轮技术栈为 Node 20 + Express + WebSocket + 原生 JS（无前端框架、无构建步骤）。因此以下元素**必须在现有依赖内做得到**，不得画出现有栈实现不了的效果：

| 元素 | 可达性 | 说明 |
|------|--------|------|
| 卡片 + 边框 + 阴影 + 圆角 | ✅ | 原生 CSS |
| CSS 变量主题 | ✅ | `tokens.css` 定义，`base.css` 引用 |
| 状态点 / 徽标 / 内联 SVG 图标 | ✅ | 原生 HTML + 内联 SVG |
| 表格 sticky 表头、行 hover、截断 | ✅ | 原生 CSS |
| 加载骨架 / 空态 / 错误态 | ✅ | 原生 DOM 三态渲染函数 |
| Toast 提示 | ✅ | 原生 DOM + CSS transition（150–250ms） |
| 危急卡片入场动效 | ⚠️ 仅允许简单 CSS transition | 不引动画库，不做复杂编排动画 |
| WebSocket 实时推送 + 断线横幅 | ✅ | 浏览器侧自动重连客户端 |
| 图表 / 仪表盘 / 3D | ❌ | 不在本轮范围，视觉目标中不出现 |

信息密度两档都要可读：1920×1080 护士站大屏，以及工控机常见的 1280 宽排班屏。
